# TCards RPG — Game

Reservado para la interfaz del jugador. Shell responsive con aventura, mochila, mapa, personaje y social. Integrará packages/swipe; sin app implementada todavía. Ver docs/ARCHITECTURE.md.

Requisitos vigentes: [UI/UX](../../docs/UI_UX.md). Mobile-first, carta central revelada sobre montón, gestos y botones, menú con mochila/mapa/ajustes; escritorio con paisaje contextual y paneles laterales. El acceso a mundos y Auth se desarrollarán por hitos.

SCE v0.2.0 es la base gráfica y de interacción principal; adaptar presentación/gestos a snapshots RPG, no motor de quiz. Ver [integración SCE](../../packages/swipe/README.md) y [primer encargo](../../docs/FIRST_TASK.md). Español único inicial, estética elegante y minimalista, temas extensibles. [Tutorial](../../docs/TUTORIAL.md) candidato gradual; no implementar entero en v0.0.2.
