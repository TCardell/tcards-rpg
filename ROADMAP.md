# Roadmap — pre-alfa

El orden prioriza un corte vertical online desde el principio. Hitos propuestos, no fechas prometidas.

| Hito | Alcance | Criterio de aceptación |
|---|---|---|
| v0.0.1 | Documentación, estructura, copia SCE | Baseline íntegro; docs y rutas coherentes; pruebas SCE ejecutables |
| v0.0.2 | Adaptador UI y contrato de comandos, motor mínimo | Seis gestos, botones y teclado; carta pendiente al abrir/cerrar mochila; acción rechazada no cambia estado |
| v0.0.3 | Supabase dev local/remoto, Auth, mundo privado y personaje | Dos identidades separadas, invitación, RLS negativa, migración reproducible |
| v0.0.4 | Expedición de dos jugadores, turno compartido | Duplicados y carrera no duplican efectos; sincronía y recuperación tras recargar/desconectar |
| v0.0.5 | Guardado local/exportación y progreso online | Restore probado, versiones y aislamiento local/online |
| v0.0.6 | Inventario, loot, equipo, oro | Transacciones atómicas, capacidad, recompensas únicas |
| v0.0.7 | Región piloto y NPC/servicios | Viaje, taberna, hostal, tienda, iglesia; contenidos validados |
| v0.0.8 | Generación procedural | Semillas reproducibles, rutas válidas, dificultad, versiones fijadas |
| v0.0.9 | PvP, traición final, panel Admin mínimo | Consentimiento de modalidad, autorización, auditoría; sin abuso de desconexión |
| v0.1.0 | Alfa privada con amigos | Pruebas en dos dispositivos reales, backup/restore, despliegue controlado, métricas y feedback |

Después: Studio, expansiones, contenido regional, economía ampliada, Realms, accesibilidad y rendimiento. No comprometer fecha ni número de jugadores sin medición.
